what's argon?
thanks & licenses

best way to save what you love

argon saves video, audio, photos and gifs from your favorite websites. paste a link and you’re done.

it’s a personal, self-hosted tool on itschu.gg, built on the open source cobalt project by imput.

access

argon’s processing server only accepts requests with an access key. if you have one, add it in instance settings.

leading privacy & efficiency

the processing server doesn’t store downloaded files. if a file needs extra processing, it’s either done on your device or streamed straight to you without being saved on the server’s disk.
